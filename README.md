## PROGRAM

## Personal Portfolio Website – HTML & CSS

Designed and developed a personal portfolio website using **HTML5 and CSS3**, focusing on a modern UI, clean layout, and responsive design.

### Key Features & Implementation

1. **Personal Introduction:** Created an attractive hero section featuring my profile, professional introduction, and role as a Full-Stack Developer and Video Editor.

2. **Featured Projects:** Added a dedicated section to showcase my projects, including project descriptions, technologies used, live demo links, and GitHub repositories.

3. **Skills & Technologies:** Organized my technical skills into categories such as programming languages, frontend development, backend technologies, databases, tools, and video editing software.

4. **Achievements:** Included a section to highlight my technical achievements, certifications, and learning experiences.

5. **Contact Section:** Added contact information with direct links to Email, GitHub, LeetCode, and LinkedIn to make professional connections easier.

6. **Modern UI Design:** Implemented a clean and minimal interface with consistent typography, rounded cards, proper spacing, and a professional color scheme.

7. **Responsive Layout:** Used CSS Flexbox, Grid, and media queries to make the website adaptable to different screen sizes, including desktops, tablets, and mobile devices.

8. **Animations & Interactions:** Added smooth transitions, hover effects, and interactive navigation to improve the overall user experience.

9. **Dark Mode:** Included a light/dark theme interface for a more comfortable browsing experience.
